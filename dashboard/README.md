# Nexus Dashboard

Dashboard web para Nexus, estilo Koya.

## Variables de entorno
- DISCORD_TOKEN
- CLIENT_ID (Application ID del bot)
- GUILD_ID (opcional)
- DISCORD_CLIENT_SECRET (OAuth2 Client Secret)
- DASHBOARD_URL (URL pública, por ejemplo https://tu-dominio.com)
- PORT

En el portal de Discord Developer, añade `DASHBOARD_URL/auth/discord/callback` como Redirect URI OAuth2.
